# BiliKiller

哔哩哔哩防沉迷浏览器扩展（Chrome / Edge，Manifest V3）。

移除 B 站页面中的推荐内容，只保留主动搜索；记录视频页的真实观看时长，达到阈值时弹出可关闭的提醒，并提供历史报表。

## 功能

| 功能 | 说明 |
| --- | --- |
| 首页净化 | 隐藏推荐信息流与二级分类导航，替换为一张白底内容卡：今日用量（今日已看 / 距下次提醒）与「稍后再看」卡片网格 |
| 视频页净化 | 隐藏右侧相关视频、底部推荐列表 |
| 热门/排行榜净化 | 隐藏榜单内容，替换为页面中央的一条搜索栏 |
| 搜索页净化 | 保留搜索结果，隐藏热搜榜等推荐位 |
| 使用统计 | 累计播放页（投稿视频 / 番剧影视 / 放映厅 / 播放列表 / 课堂 / 直播）在标签页可见且正在播放的时长；暂停、缓冲、切走标签页、首页/搜索/热门页、静音悬浮预览、总开关关闭均不计时。按天持久化，每天 0 点清理 90 天前数据 |
| 温和提醒 | 观看时长每达到设定阈值（默认 30 分钟，可配置 10–120 分钟）弹出提醒：「继续观看」仅延迟、「暂停播放」会暂停视频再延迟、「今天不再提醒」推迟到当天结束；延迟与「今天不再提醒」按天记录，跨天自动失效 |
| Popup | 今日观看时长、访问次数、近 7 天迷你趋势图、各净化功能快捷开关；固定 600px 高度，开关区在中间滚动，设置入口始终可见 |
| Options | 分项开关各隐藏规则、配置提醒间隔、查看近 30 天历史报表柱状图 |
| 首页用量 | 首页面板顶部一行「今日已看 · 距下次提醒」，12px 灰字，每 30 秒刷新，提醒关闭时显示「已关闭」 |
| 外观 | 全站沿用 B 站自身的设计令牌：哔哩哔哩粉 `#FB7299`、文字 `#18191C / #61666D / #9499A0`、描边 `#E3E5E7`、圆角 8px、苹方／鸿蒙字体；Popup 与 Options 跟随系统深浅色，注入面板跟随站点深浅色 |
| 深色模式适配 | 自动跟随 B 站深色开关（`html.bili_dark`，兼容旧版 `html.dark`），首页面板 / 视频统计 / 热门占位 / 提醒浮层 / 用量胶囊全部颜色采用 CSS 变量，亮/暗双主题无缝切换，无白块刺眼 |
| 稍后再看 | 首页展示你加入 B 站「稍后再看」的视频（封面 / 标题 / UP 主 / 时长），未登录、为空或加载失败时显示对应提示 |
| 全站广告 | 屏蔽视频页右侧广告卡片与底部横幅、搜索页推广位等广告容器，与净化规则相互独立可单独开关 |
| 沉浸观看（弹幕 / 评论区） | 可选隐藏视频页弹幕层与评论区，只留画面与声音，屏蔽情绪化与引战内容的注意力黑洞（默认关闭，与播放互不影响） |
| 视频页观看统计 | 播放页右侧栏（广告与相关推荐被净化后留白处）注入「观看统计」面板：今日已看 / 本次连续观看（全站统一累计，跨视频跨标签页同一计数，空闲 30 分钟后重新计数）/ 距下次提醒，每 30 秒自动刷新 |
| 图标徽章 | 扩展图标右下角实时显示今日观看分钟数（>99 显示 `99+`），每次心跳写入后刷新，无需打开 Popup 即可瞥见用量 |
| 专注模式 | 默认关闭：开启后当日观看满设定分钟数（默认 90）时，视频页暂停播放并弹出全屏提示（「回首页」/「再看 5 分钟」） |
| 专注褪色 | 观看满设定分钟数（默认 60）后，整个 B 站页面转为灰度（`backdrop-filter: grayscale`，不拦截点击、不改布局），可在用量胶囊一键「临时恢复色彩 15 分钟」 |
| 全局用量胶囊 | B 站任意页面左下角常驻今日用量小胶囊：实时显示今日分钟数，点击展开「今日已看 / 距下次提醒 / 今日访问 / 褪色状态 / 打开设置」 |
| 数据管理 | Options 页支持一键导出 JSON 备份、导入恢复、清空统计（净化设置保留），所有数据仍仅存本机 |

## 安装

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）；
2. 开启右上角「开发者模式」；
3. 点击「加载已解压的扩展程序」，选择本目录（包含 `manifest.json` 的文件夹）；
4. 访问 bilibili.com 即可生效。

## 技术要点

- **零依赖、无构建**：原生 JS + HTML + CSS，直接加载即可运行。
- **CSS-first 净化**：`document_start` 注入隐藏规则，CSS 对动态节点天然生效、零重排开销；钩住 `history.pushState` / `popstate` 适配 SPA 路由；节流 MutationObserver 仅作兜底。
- **真实观看计时**：`player.js` 统一探测主播放器 video 并维护「播放/缓冲/暂停/结束/无视频」状态（事件驱动），`tracker.js` 仅在 `state=playing` 时用 `performance.now()` 精确到毫秒累计（排除暂停 / 缓冲 / 静音悬浮预览 / 后台标签页 / 首页搜索热门页 / 总开关关闭），覆盖投稿视频、番剧影视、放映厅、播放列表、课堂与直播；「暂停播放」暂停视频即停止计时，统计贴近真实观看。
- **写入节流**：时长每 15 秒心跳上报一次 + 页面隐藏/卸载时立即上报，service worker 串行化写入避免多标签页竞争。
- **跨标签页会话状态**：提醒的「已提醒阈值」与「延迟到何时」存入 `chrome.storage.local`，多标签页共享，避免开新标签页后重复打扰。
- **爆炸半径控制**：content scripts 仅匹配 `*://*.bilibili.com/*`，不影响其他网站；所有功能均可在选项页独立关闭。

## 选择器维护指南

B 站改版导致净化失效时，只需更新 `src/content/selectors.js`：

1. 打开失效页面，用开发者工具定位推荐内容容器的真实 class；
2. 在对应规则组（`hideHomeFeed` / `hideRelated` / `hideHotRank` / `hideHotSearch`）的 `selectors` 数组**头部**追加新选择器；
3. 保留旧选择器作为兜底，无需改动其他文件。

选择器于 2026-08 通过真实 bilibili 页面实测采集（首页 `.bili-feed4-layout`、视频页 `.recommend-list-v1`、热门页 `.popular-container`、热搜 `.trending`）。

## 端到端验证

仓库自带 playwright-cli 验证配置 `.playwright/e2e.config.json`（以持久化上下文加载本目录为未打包扩展）。配置中的 `<PROJECT_ROOT>` 占位符需先替换为本机扩展目录绝对路径（如 `d:\Code\BiliKiller`），再执行：

```powershell
playwright-cli --config=.playwright/e2e.config.json open https://www.bilibili.com/
```

修改 JS / manifest 后可先做本地语法校验（遍历 `src` 下全部 JS 并校验 `manifest.json`）：

```powershell
node tools/check-syntax.mjs
```
